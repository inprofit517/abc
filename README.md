# abc Elektrotechnik AG — Demo

Statische Landingpage (Hero + Navbar) für abc Elektrotechnik AG.

- Reines HTML/CSS, kein Build-Schritt
- `index.html`, `styles.css`, `assets/`
- Schriften via Google Fonts (Bricolage Grotesque, Hanken Grotesk)

## Lokal ansehen

```bash
python3 -m http.server 4601
```

Dann http://localhost:4601 öffnen.

## Deployment (Netlify)

Kein Build-Command nötig. Publish-Verzeichnis: Repository-Root (siehe `netlify.toml`).

> Hinweis: Die Telefonnummer im Code ist ein Platzhalter und muss vor dem Livegang ersetzt werden.
